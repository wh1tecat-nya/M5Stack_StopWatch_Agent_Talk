# Sumi StopWatch 会話ハブ

既存のすみの会話へStopWatchの発話を送る開発用Chrome拡張です。音声の録音・読み上げはStopWatch本体で行い、返答は既存の `submit_stopwatch_reply` から受け取ります。ChatGPT内部の非公開APIは使用しません。

## 権限とデータ

- `activeTab`: 拡張をクリックして選択したタブへの一時的なアクセス。
- `scripting`: 選択したすみの入力欄へ発話を入力し、送信する処理。
- `storage`: 選択したタブIDと送信済み発話IDを、ブラウザーを閉じるまで保持。
- 外部メッセージの受信元は、既存Workerの中継ページだけに限定しています。接続時に開いた中継タブのIDも確認します。

全サイトへの常時アクセス権限は要求しません。APIキー・オーナーキー・ChatGPTのCookieを拡張へ保存しません。既存の下書きや添付がある場合は送信せず、送信結果が不明な場合も自動再送しません。

## 導入

1. Chromeの拡張機能管理画面でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から、この `browser-extension` フォルダーを選択します。
2. 既存のすみの会話を開き、拡張のアイコンから「このすみに接続」を押します。
3. 自動で開く中継ページで、必要なら「履歴と同じオーナーキーでログイン」を開いてログインします。キーをチャットに貼る必要はありません。
4. 中継ページへ戻り、「開始」を押して「接続中」を確認します。
5. StopWatchの左ボタンを押して話し、離して送信します。

使用中は中継ページとすみのタブを開いたままにします。タブを再読み込みした場合は、拡張から接続し直してください。停止すると新しい発話は従来のイベント経路へ戻ります。閉じた場合は最大45秒後に戻りますが、取得済みの発話を重複して再配送することはありません。

## 検証範囲

選択タブ・接続元の制限、下書き保護、改行の扱い、二重送信防止、Worker認証、既存の返答回収に加え、接続タブの登録が完了してから小窓を閉じる順序を含む15テストが通過しています。2026-11-07に接続完了と、StopWatchの発話→既存すみの会話→本体での読み上げを実機で確認しました。今回の発話と返答は既存すみのチャットにも表示され、ユーザーが本体から聞こえたことを確認しています。

1回の計測では、左ボタンを離してから再生キュー投入まで29.056秒、本体TTS合成は1.949秒でした。Worker側では、会話画面への送信から返答ツール受信まで21.192秒でした。再生キュー投入は実際の発音開始と同一の計測点ではなく、応答時間の保証でもありません。[計測の内訳](../docs/latency-routes.md#chrome拡張経路の実機計測)
